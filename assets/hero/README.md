# Imágenes del hero (opcional)

El slider de la Home puede mostrar una imagen encima del texto de cada slide.
Si no hay imagen, el slide se ve igual que ahora (sin hueco vacío ni error) —
así que esta carpeta puede quedarse vacía sin problema.

No generamos ni descargamos fotos reales de jugadas/jugadores de la NFL: son
contenido con copyright de la propia NFL/equipos, así que hay que subirlas
vosotros (capturas propias, fotos con licencia, etc.).

Para activar la imagen de un slide, añade un archivo con **exactamente** uno
de estos nombres (cualquiera de estas extensiones vale: `.jpg`, `.jpeg`,
`.png`, `.webp`):

| Slide                          | Nombre de archivo |
|---------------------------------|--------------------|
| Highlights de la jornada         | `highlights.jpg`  |
| General (clasificación/equipos)  | `general.jpg`     |
| MVP de la jornada                | `mvp.jpg`         |
| Próximo partido clave             | `big_game.jpg`    |
| Trivia / Quiz                    | `trivia.jpg`      |

Recomendado: imágenes horizontales (~1200×500px o similar), peso razonable
(unos pocos cientos de KB) para que la Home no tarde en cargar.
